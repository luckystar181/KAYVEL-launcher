# KAYVEL Launcher

Лаунчер Minecraft для Windows 10/11 x64 на Electron и React. **Версия для разработки, не готовая игровая поставка.** Входа и аккаунтов KAYVEL нет: игрок сохраняет ник локально, whitelist ведётся на сервере. Парольный серверный мод выбирается отдельно; лаунчер не принимает его пароли.

Этот репозиторий начинается с чистой истории. Прежние API, Core, ticket bridge, клиент аккаунтов и сценарии локальных служб сюда не перенесены. Игровые файлы, Java, моды, миры, пользовательские профили и приватные ключи в репозиторий не входят. Старые установки не изменяются и автоматически не мигрируются.

## Что работает

- Локальный ник из 3–16 латинских букв, цифр и `_`.
- Выбор PNG 64×64 или 64×32 до 1 MiB, Classic/Slim, 3D-предпросмотр и отдельные копии скина без изменения исходного PNG.
- Поиск варианта скина по нику через сервисы Minecraft. Требуется сеть; это не вход и не проверка личности.
- Локальные новости, мини-игра и сохранение её рекорда.
- Проверка Ed25519, размера и SHA-256 файлов подписанного модпака; обратимые переключатели трёх конкретных модов для будущей новой установки.

**Скин пока не устанавливается в Minecraft и не виден другим игрокам.** Общий источник скинов, его хранение и защита не выбраны; CustomSkinLoader не перенастраивается.

## Что пока отключено

Подготовка Minecraft 1.21.1 и NeoForge 21.1.252 заблокирована в интерфейсе, IPC и точках входа установщиков. Старые загрузчики не гарантируют сохранность занятых путей и отсутствие запасных запросов. Установка модпака через интерфейс тоже отключена: для неё нужен отдельно согласованный подписанный выпуск **без KAYVEL Core**. Прежний релиз не используется.

Автоскачивание всей сборки пока не готово. Автообновление, автоматическое восстановление, удаление и принятие старых игровых файлов не реализованы. Наличие кода загрузчика или зелёного индикатора не подтверждает готовность игры.

Запуск уже подготовленных файлов требует имеющейся Java 21 и отдельного положительного подтверждения сетевой изоляции **перед каждым запуском**. Лаунчер не создаёт и не проверяет изоляцию. Не запускайте Minecraft, сервер или службы без отдельного согласования; не открывайте сервер в интернет без согласия владельца.

При `online-mode=false` ник не подтверждает личность, а игровой трафик сам по себе не шифруется. Whitelist не заменяет проверку личности и защиту будущего парольного мода. Саморегистрации и серверного управления игроками в лаунчере нет.

## Разработка

Нужны Windows 10/11 x64, Node.js 24 и npm 11. Установка зависимостей требует сети и может выполнить установочные скрипты зависимостей, включая загрузку Electron; запускайте её осознанно:

```powershell
npm ci --fetch-retries=0 --no-audit --no-fund
```

Проверка типов, сборка и изолированные тесты:

```powershell
npm run check
npm test
```

`npm test` собирает приложение и запускает Node-тесты из `tests/`. В этом репозитории нет прежних тестов auth/Core, интеграционных служб и тестов, поднимающих HTTP-серверы. Ответы сети в тестах подменяются; Minecraft, серверы и Java-установщики не запускаются. Некоторые тесты создают дочерние процессы Node и временные файлы. По умолчанию используется системный временный каталог; его можно задать через `TEMP`, `TMP` и `KAYVEL_TEST_TMPDIR`.

Открыть окно приложения, не запуская игру:

```powershell
npm start
```

Окно читает локальные данные Electron из `%APPDATA%\kayvel-launcher`; это не обязательно пустой профиль. Для изолированной проверки используйте отдельный тестовый профиль, а не удаляйте прежнюю Java, моды или миры. Перед добавлением новых тестов отдельно проверьте их сетевое поведение.

## Переносимая папка Windows

```powershell
npm run package:portable -- --output-name KAYVEL-local-preview
```

Результат — `dist\portable\KAYVEL-local-preview\KAYVEL.exe` и файлы рядом. Переносить нужно **всю папку**, не один EXE. Упаковщик использует уже установленный Electron и локальный npm-кэш для production-зависимостей (`npm ci --offline --omit=dev --ignore-scripts`). Сам он не запрашивает сеть и не запускает install-скрипты. Недостающий кэш приводит к остановке без сетевого fallback.

Существующий результат не перезаписывается. При ошибке частичная папка остаётся для проверки; исправьте причину и выберите новое имя, а не повторяйте операцию наугад. Упаковщик переносит только зависимости `main.js` и `preload.cjs` и отклоняет ссылки на прежние модули аккаунтов.

EXE не подписан Authenticode и не является установщиком. Не отключайте защиту Windows ради его запуска. Проверка на текущем компьютере не заменяет проверку на чистой Windows. В папку приложения не входят Minecraft, управляемая Java и моды. Локальные данные по умолчанию хранятся отдельно от EXE в каталоге Electron, а не внутри переносимой папки.

## Профиль и сохранность данных

Ник и скин сохраняются локально в `local-player` внутри `userData` Electron. Новый PNG или смена ника создают отдельную копию `skin-copies\<UUID>\<ник>.png`; прежние копии автоматически не удаляются. При смене offline-ника может измениться игровая личность и доступ к вещам в мире.

История ограничена 256 ревизиями. Повреждённая или неполная запись блокирует дальнейшие изменения; отсутствующий PNG не восстанавливается автоматически. После аварии могут остаться частичные файлы или `profile.lock`. Не удаляйте их наугад.

SHA-256 связывает ревизии, но не превращает их в защищённый журнал или резервную копию: удаление последней ревизии или полная локальная подмена могут остаться незамеченными. Блокировки кооперативные; внешние программы способны менять файлы. Резервирование и восстановление требуют отдельного решения.

## Переключатели модов

Поддерживаются точные имена:

- `iris-neoforge-1.8.14-beta.1+mc1.21.1.jar`;
- `DistantHorizons-3.3.3-1.21.1-fabric-neoforge.jar`;
- `SSRD-1.8.8-1.21.1.jar`.

Переключение между `mods` и `.kayvel\disabled-mods` требует корректной подписи Ed25519, размера, SHA-256, метки происхождения новой установки и отсутствия незавершённой установки. Изменённые, отсутствующие или неоднозначные файлы приводят к остановке, не к автоматическому ремонту. Сбой между созданием жёсткой ссылки и удалением исходного имени может оставить два имени одних данных; не удаляйте их без проверки.

Совместимость и права распространения не подтверждены. Метаданные указанного Iris формально исключают Minecraft 1.21.1; SSRD требует `sodium` и `sable`, его лицензия — `All Rights Reserved`. Подпись не проверяет безопасность, совместимость или право распространения. Если удалить и метку, и манифест, прежний модпак не всегда отличим от отдельной неуправляемой установки NeoForge.

## Отдельный подписанный выпуск

`scripts/prepare-github-release.mjs` локально готовит новый набор из отдельно выбранных `mods\*.jar` и `resourcepacks\*.zip`. Он требует нового тега, новой папки результата, подтверждения прав и приватного Ed25519-ключа **вне проекта и исходной папки**. Сам инструмент ничего не публикует. Подтверждение оператора не является независимой проверкой лицензий; для известных ограниченных файлов есть дополнительное подтверждение.

Приватные ключи, токены и пароли нельзя помещать в git, исходную папку, приложение или GitHub Release. После подписи нельзя менять байты манифеста и файлов. Прежний публичный ключ сохранён; URL релиза пуст и установка заблокирована. Новый состав и безопасное подписание согласуются отдельно. Старые опубликованные файлы и ключи не меняются автоматически.

Подпись подтверждает целостность относительно закреплённого ключа, но не защищает от всех локальных изменений. Защита от отката к прежнему корректно подписанному выпуску пока не реализована.

До публичного размещения игровых служб отдельно согласуются архитектура, защита каналов, секреты, хранилище, резервирование, восстановление и расходы. В этом репозитории нет развёртывания игрового сервера и платной инфраструктуры.
